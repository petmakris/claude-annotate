01 · THE PROBLEM
Most failures are not real declines

One payment in forty fails on the first try because the gateway times out.

The card is fine; a second try a few seconds later goes through.

Today the buyer sees an error and has to type the card again.

A timeout is not a decline. Treating it as one sends buyers away at the last step.
3
01 · THE CHANGE
One quiet retry, then a clear answer
  • When the gateway times out, checkout waits two seconds and sends the same payment again, with the same idempotency key so the card is never charged twice.
  • A real decline is shown at once, with no retry.
  • Every retry is logged with the order number.
